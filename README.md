## 🧠 Sobre mí

No escribo código para “que compile”.  
Escribo código para que **escale**, **se mantenga** y **no explote en producción**.

Soy **Desarrollador Full Stack**, con enfoque fuerte en **backend, bases de datos y arquitectura**, pero con experiencia sólida en **Angular y React** cuando el producto lo exige.

🚀 **Founder & Developer de _App Tu Calle_**, una red social de recomendaciones de comida enfocada en negocio local real.

---

## ⚡ Cómo trabajo (mentalidad senior)

- 🧱 Pienso en arquitectura antes que en features  
- 📉 Optimizo queries antes de subir recursos  
- 🔁 Automatizo lo repetitivo  
- 🧪 Prefiero simple + robusto que complejo + frágil  
- 🔥 Si algo se rompe, lo arreglo… y queda mejor
